# 相纸炼金

**一张照片，两种去路：保留它，并重新想象它。**

一个把用户照片转化为纸感海报/极简插画的通用智能体技能。先阅读现场，再同时走两条路——**默认双输出**：

- **实景拼贴** — 保留原始照片作为真实锚点，用简化插画、结构性色彩和手撕纤维边缘重组为纸感海报。
- **影像蒸馏** — 不保留原图，从照片中提取语义核心和情绪张力，重新创作一件独立的极简插画作品。

## 两种风格

| | 实景拼贴 | 影像蒸馏 |
| --- | --- | --- |
| **照片的角色** | 成为成品中的真实视觉锚点 | 只作为语义与情绪来源，不进入成品 |
| **转化方式** | 摄影 + 简化插画 + 结构性色彩 + 手撕纤维边界共同构图 | 从事实中提取命题、张力与隐喻，重新创作 |
| **结果** | 真实而克制的纸感拼贴海报 | 表达优先的极简编辑插画 |
| **触发** | 默认与蒸馏一同输出；也可用"只做实景拼贴"单独触发 | 默认与拼贴一同输出；也可用"重新创作 / 不保留原图 / 只做影像蒸馏"单独触发 |

## 核心方法论

本技能采用一套完整、自洽的创作方法，贯穿两种模式：

- **先读现场**：任何创作前建立场景档案（核心主体、空间不变量、主导手势、视觉重量、色彩氛围、语义最小集、情绪余韵），照片是唯一事实来源。
- **关系优先**：保留让场景成立的少量关系与最低辨识度，而不是复刻物体；先保关系、再保细节；先删细节、再加装饰。
- **解构 → 保留/蒸馏 → 重构**：解构照片的空间、色彩与情绪事实，选择性保留（拼贴）或超越（蒸馏），再重构为一件完整的纸面作品。
- **做减法**：复杂度越高，简化越狠——密集树叶、人群、砖石压成少量大的安静形体；留白是主动的参与者。
- **量化纪律**：明确的留白占比、色彩面积、纤维带宽与文字长度约束，按实际视觉重量校正，绝不为数字牺牲场景身份。
- **一个原则**：一个主要插画语法、一个结构性色彩、一个中心隐喻、一条微文本。颜色必须干活（结构移除测试），装饰必须有来源。

## 安装与使用

本技能使用**通用标准 SKILL.md 格式**（YAML frontmatter 声明 `name` + `description`，正文为工作流指令），可被多种智能体直接安装，无需转换：

| 智能体 | 安装位置 |
| --- | --- |
| OpenAI Codex | `~/.codex/skills/photo-paper-alchemy-v2-0/` |
| Claude Code | `~/.claude/skills/photo-paper-alchemy-v2-0/` |
| Cursor | 项目 `.cursor/skills/` 或全局 `~/.cursor/skills/` |
| Windsurf | `.windsurf/skills/` |
| GitHub Copilot (VS Code) | `.github/skills/` |

```bash
# 以 Claude Code 为例
mkdir -p ~/.claude/skills
cp -R photo-paper-alchemy-v2-0 ~/.claude/skills/
```

安装后重启对应智能体，上传照片并调用，例如：

> 使用 `photo-paper-alchemy-v2-0` 处理这张照片。（默认双输出：实景拼贴 + 影像蒸馏各一张）
>
> 使用 `photo-paper-alchemy-v2-0` 把这张照片做成实景拼贴海报，保留人物与海的关系。（仅实景拼贴）
>
> 使用 `photo-paper-alchemy-v2-0` 重新创作这张照片，不要保留原图，表达"靠近与错过"。（仅影像蒸馏）

技能会返回成品图 + 简短创作说明；完整提示词只在要求时给出。

### 兼容性说明

- **标准格式**：`SKILL.md` + `name`/`description` frontmatter 是 OpenAI Codex、Anthropic Agent Skills 开放规范、Claude Code、Cursor、Windsurf 共同采用的结构；文件夹名与 frontmatter `name` 一致（`photo-paper-alchemy-v2-0`），通过严格校验。
- **`agents/openai.yaml`**：Codex 专属的界面元数据文件；其他智能体会安全地忽略它，不影响安装与使用。
- **未声明 `allowed-tools` / `disable-model-invocation`**：按规范默认允许全部工具、允许模型自主调用本技能——这是跨智能体兼容性最优的选择；若目标环境需要限制工具，可自行在 frontmatter 中添加对应字段。
- **图片生成依赖**：技能使用宿主智能体自带的图像生成能力（Codex 内置生图、Claude 的 `ImageTool` 等）；调用时需把用户照片作为参考图传入。

## 关于照片与隐私

技能只把用户提供的照片作为当前生成任务的参考。除非用户明确要求，不浏览、分享、另行上传或保存原始照片。
