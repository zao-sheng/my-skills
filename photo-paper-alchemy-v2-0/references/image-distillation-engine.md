# 影像蒸馏引擎（模式 B）

**把照片当作语义证据与创作刺激，绝不当作成品中的视觉图层。**

不在成品中保留原始照片。从照片中提取语义核心、情绪张力和视觉隐喻，再用纸张、插画、色彩与自由文字重新创作一件独立的极简编辑插画作品。

## 决策优先级

冲突时按此顺序解决：

1. 确立一个具体的艺术命题并让它可见地成立。
2. 从源构建一个核心情绪或概念张力。
3. 创作一件有独立美学声音的完整作品。
4. 保留源的语义核心与情绪来路。
5. 有目的地重组、简化、夸张与发明。
6. 建立图底清晰、层级、平衡与有意的视线路径。
7. 让边界、材料、色彩、空间与文字服务命题。
8. 保留大量安静空间与一个阐释开口。
9. 忠实应用所选色彩模式，有目的地使用高纯度。
10. 保持成品可触、平面、诗意、非商业。

这不是照片滤镜、风格迁移、转描或字面插画拷贝。

## 蒸馏卡

动笔前先解析：

- **语义核心**：让源获得意义的最小主体、关系或事件。
- **核心主体**：一个主体，或最多两个不可分离的主体。
- **支撑元素**：1–3 个确立地点、季节、动作或氛围的元素。
- **主导手势**：最强的注视、倾斜、曲线、斜线、路径、重复、汇聚或运动。
- **空间线索**：值得保留的一个源关系（近/远、上/下、相对、遮挡、包围、方向）。
- **视觉重量图**：面积、明度、饱和度、人脸、孤立感、边缘张力与纹理造成的重量。
- **原生色板**：主导色相族、冷暖、明度范围、有意义的次要色。
- **材料与天气**：水、雪、雾、玻璃、枝叶、石、织物、风、雨或光的行为。
- **情绪余韵**：去除事实描述后剩下的感受。
- **可丢弃清单**：背景细节、杂物、冗余物体、应当消失的写实信息。
- **可转化机会**：可以被放大、合并、碎片化、重复、移位或变成负空间的形体。

只保留 **2–4 个源锚点**。默认不保留原构图。

## 表达引擎

```text
源事实 → 情绪余韵 → 表达命题 → 核心张力 → 视觉隐喻 → 形式具象 → 阐释开口
```

### 表达命题

写一句内部陈述：作品要让观众**感受到、注意到或重新思考**什么。必须是关系性的、源特有的。

好的例子：

- 一个小人物遇上了大到无法掌控的尺度，却不显挫败；
- 庇护与隔绝存在于同一个包围形体里；
- 一个普通物件穿过变迁之地承载着记忆；
- 一个开口许诺自由，同时标记了分离。

避免"安静""治愈""怀旧""梦幻""美好"这类泛标签——除非可见结构解释了那种感受为何存在。

### 核心张力

从源中选择一个已经存在或可信浮现的主要对立：

亲密/距离 · 庇护/禁锢 · 运动/静止 · 渺小/浩瀚 · 温暖/寒冷 · 记忆/消失 · 秩序/生长 · 显/隐 · 永恒/脆弱

可选一个次级张力。不要堆叠多个无关主题。张力通过尺度、间隔、方向、重叠、包围、中断、冷暖、明度或材料对比表达，而不是通过解释性文字。

### 视觉隐喻

把源中的一个物体、空间关系、材料行为或手势转成中心隐喻。保留足够的特殊性，让隐喻显得**从照片中发现**而非事后强加。

允许物体转换功能：容器承载记忆、窗变成心理边界、雪既庇护又抹除、山变成距离、枝变成时间、车变成迁徙。这些是推理示例，不是固定符号字典。

只用一个中心隐喻。避免通用符号陈词、过度符号化和任意超现实添加。

### 形式具象

让每一个主要形式选择执行命题的一部分：

- **尺度与空间**：表达力量、脆弱、距离、孤独、释放或持续。
- **方向与节奏**：表达靠近、抵抗、漂移、重复、中断或回归。
- **边界与边缘**：表达分离、破裂、累积、消退、通过或突破。
- **色彩**：作为情绪事件——温暖到来、伤口张开、信号呼唤、距离加深、生命坚持。
- **材料**：让撕纸纤维、干墨、颗粒、剪纸、断轮廓承载心理意义，而非表面装饰。
- **文字**：扩展、转向或轻微复杂化图像；不要只是给可见之物加字幕。

删掉任何唯一功能是"让画面看起来有艺术感"的元素。

### 阐释开口

确定作品的情绪方向，但留下一个关系**不回答**。给观众足够的视觉证据进入作品，却不固定单一字面解释。歧义来自有意义的省略、遮挡、尺度错位、未完成动作或文字–图像间隙，而不是随机晦涩。

## 作者性重构

把源当作起点，不是答案。允许：

- 改变尺度、比例、裁切、间距、方向与位置；
- 重组原空间关系；
- 把几个元素合并成一个新的视觉团；
- 分裂、重复、延伸或节奏性压缩一个元素；
- 删除写实背景，只留暗示性痕迹；
- 夸张手势、距离、方向、轮廓或材料行为；
- 让形体跨过、消失于后或突破撕纸边界；
- 把风、水、光、影、雪或运动变成抽象场与标记；
- 发明源一致的支撑形体（不必字面可见）；
- 重新设计色板以改善层级与情绪力度；
- 从图像的具体线索或情绪余韵写一段短文字。

每个发明必须至少干一份活：延伸源情绪、澄清主体关系、建立节奏、平衡视觉重量、引导视线、强化中心隐喻。删掉只为"显得有设计感"而存在的添加。不要默认使用圆点、网格、胶带、印章、坐标、十字、英文碎片或几何装饰。

成品必须能在没有源图的情况下独立成立。与源图对比时，联系应微妙、具体、可信。

## 抽象与插画语法

默认**编辑性抽象**：

- 保留语义核心、主导手势、一个源特有线索；
- 移除约 65–90% 的描述性细节；
- 用简化块面、断轮廓、纸片、稀疏标记或印刷场取代写实渲染；
- 泛化面部身份，除非用户明确要求肖像；
- 在不破坏语义核心的前提下允许改变解剖或透视。

只选一种主要语法，最多一种辅助语法：

| 语法 | 形态 |
| --- | --- |
| 剪纸团块 | 不规则扁平形承载主体与视觉重量 |
| 干印剪影 | 一个宽墨块保留手势或轮廓 |
| 断轮廓 | 断续线条保留方向、姿态或结构 |
| 节奏场 | 重复标记压缩人群、叶、浪、雪、窗或运动 |
| 碎片堆叠 | 两到三个重叠纸形分配主体与场景 |
| 轨道/漂移 | 选定形体沿源衍生路径离开中心簇 |

避免完整轮廓、均匀细节、写实明暗、抛光矢量人物、可爱卡通、日系可爱风、动漫、童书甜腻（除非明确要求）。

## 构图导演

保留源方向，除非用户要求其他比例：

- 竖幅源 → 竖向 3:5；
- 横幅源 → 横向 5:3；
- 方形/缺失/方向不明 → 竖向 3:5。

把方向当作源空间逻辑的一部分，不只是导出设置。在选定画布内自由重组；不保留摄影取景，也不仅为填满横向格式而放大插画。

起点：

- 68–85% 安静纸面；
- 一个活跃插画簇约占 12–32%；
- 一个主导团、一到三个支撑形、一个克制纹理场。

用实际视觉重量校正。一个深色脸大的形体可能比一个淡色大场更重。

### 构图族（从源几何选择）

| 构图族 | 说明 |
| --- | --- |
| 不对称孤岛 | 紧凑的偏离中心簇，四周是呼吸空间 |
| 撕纸窗口 | 不规则纸边界包含主形，一个元素逃逸 |
| 方向漂移 | 形体沿注视、路径、风、海岸线或运动向量延伸 |
| 节奏循环 | 重复元素形成开放环流，不要默认正圆 |
| 错位碎片 | 两到三片分离纸件建立序列与间隔 |
| 竖向张力 | 低或高主体团被远处一个光点/细条对位 |
| 辅助星座 | 孤立一个核心主体，再把一个源衍生支撑元素散布为不等视觉节拍，建立节奏、尺度与视线路径 |

应用：图底清晰、不对称平衡、主从层级、光学而非机械居中、格式塔邻近/连续/闭合、尺度与间隔对比、方向性呼吸空间、明确的视线路径（入口 → 焦点相遇 → 运动 → 安静出口）。

把布局当作起始语法，不是模板。不要习惯性居中，不要均分画面。

## 过渡边界导演

从源几何、材料情绪与表达命题中选择**一种**主要边界处理。主要选择可以是安静的**自然孤立轮廓**（无可见过渡效果）。可选加一种辅助处理，仅当它澄清深度、运动或过渡时。绝不在一张图里应用所有手法。

| 边界 | 做法 |
| --- | --- |
| 撕纸纤维边 | 不规则暴露纤维与破纸轮廓划分活跃插画与空白纸 |
| 分层灰度边 | 沿撕口放两到三条极窄不规则中性带（浅灰/中灰/克制炭灰），形成浅材料分离，无投影 |
| 点蚀溶解 | 稀疏点、半色调碎屑或破颗粒把边缘松进周围纸面；密度与方向源自源运动 |
| 不规则标记边 | 沿过渡放 1–3 个小的源衍生图形，延续节奏或方向；保持中性从属 |
| 自然孤立轮廓 | 只保留原本就插画化的主体与必要支撑，干净有机轮廓直接落在纸上；仅在需要时于轮廓处加淡墨咬或纸颗粒。不加撕口、灰度缘、点蚀场、光晕、边框或任何可见过渡装置 |

每种处理：

- 对齐源的某个地平线、手势、路径、压力、材料变化或方向断裂；
- 使用正负形，允许内部纸隙；
- 让 0–2 个选定形体在有助于延续时跨过边界；
- 浅深度、可触、平扫；
- 纯色块模式下所有边界标记保持中性。

**避免**：单一通用撕碎矩形、所有边缘手法齐用、装饰性符号散落、拼贴簿分层、胶带、漂浮纸、重投影、卷纸、斜角、写实 3D 深度。自然孤立轮廓借用干净剪贴的视觉逻辑而非摄影像素；保留的每个形体都必须重新插画化。避免贴纸描边、硬数字剪贴、模糊选择光晕、写实剪切碎片。

## 色彩模式政策

默认**标准强调模式**。选择色相前先做**色彩决策**：

- **视觉角色**：焦点入口、对位砝码、桥、空间场或方向线索。
- **源关系**：共鸣、同类和谐、冷暖对位或聚焦互补。
- **明度对比**：相对纸与中性墨需要多亮或多暗。
- **彩度**：必须与素净/中性形分离到什么程度。
- **材料形式**：孔版印刷墨、不透明剪纸、扁平剪影、干印块或纸本处理。
- **面积与邻接**：需要多少色、必须接触或对抗哪个形。

不要默认蓝色或任何固定色板。选择最服务源、构图、情绪温度与视线路径的色相。可接受的高纯度色包括但不限于：饱和钴蓝孔版印刷墨、不透明群青剪纸、鲜明梨绿扁平剪影、干净番茄红印块、柠檬黄干印场、饱和洋红粉纸团、清晰橙色活版印刷形。

仅当用户请求**精确包含**触发词时才切换纯色块模式：

```text
单色块模式
```

示例："用 $photo-paper-alchemy-v2-0 的单色块模式处理这张图片"。不要因为源图或成品极简就推断该模式。触发词缺失则保持标准强调模式。

## 标准强调模式

把色相、明度、彩度分开分析。纸与大部分插画墨保持素净，然后用一个毫不含糊的高纯度色。

按功能选强调色：

- **源共鸣**：强化一个有意义的次要源色。
- **冷暖对位**：冷源加暖色，或暖源加冷色。
- **聚焦互补**：互补或近互补色锐化焦点关系。
- **安静和谐**：需要统一胜过张力时用更强的同类色。

指定精确色相与材料形式。绝不因为某个色相出现在示例里就选它。

给强调色一个主角色：焦点钉、对位砝码、碎片桥、方向线索、节奏节拍。

高纯度总面积约占全图 0.8–3%，或活跃簇的 10–30%。一个主强调色 + 可选一到两个更小的回声；所有回声合计低于强调色面积的 25%。

通过强调色陈述预期的视线路径。不要无缘无故加亮块。不要用"苍白/柔和/褪色/粉彩/低饱和"削弱它（除非用户要求）。

### 分散支撑强调

仅当源包含有意义的可重复支撑元素（花、叶、果、鸟、小灯、石、窗、工具或其他可识别母题，且其色彩贡献于地点/情绪/季节/叙事）时使用：

- 保留元素身份与色彩方向，再用选定插画语法重绘；
- 围绕核心主体散布多个实例：不等尺度、间隔、方向与密度；
- 整个散布集使用**一个**精确高纯色相，读作一个色彩系统而非多个竞争强调；
- 让散布元素建立入口、循环、对位与出口；不要排成均匀装饰边框或重复图案；
- 饱和总面积保持在标准强调额度内；散布集取代通常的主强调 + 回声，不增加色彩系统；
- 保留有意义的缺席：留一些间隔空白，让观众完成节奏。

源缺少可信支撑元素时不要发明散布母题。避免彩纸屑、任意花瓣、装饰性撒花、等距、完全相同的复制品、与表达命题无关的色彩点。

## 纯色块模式

触发 `单色块模式` 时，全图恰好三类色彩：

1. 自然纸色；
2. 统一的无彩色/近中性墨系统（所有轮廓、物体、纹理与文字）；
3. **恰好一个连通的全饱和色场**。

约束：

- 所有非强调形体只用炭灰、石墨、暖灰、棕黑或近黑墨。
- 支撑形体不得用素净的蓝、绿、红、黄、紫或其他彩色调。
- 用一个高纯度色相做成一个连通的填充形；不拆成回声、点、条纹或分离彩色物体。
- 色场约占全图 3–12%，或活跃簇的 25–65%。
- 视觉上实心不透明；允许内部纸颗粒、墨咬与微小印刷缺陷，但保持连续色读。
- 把色场当作主体、开口、窗、门、太阳、水体、剪影、室内空间或其他源衍生核心形。
- 让色场成为视觉入口或中心空间观念，而不是摆在作品旁的装饰矩形。
- 轮廓与位置派生自源的语义核心、主导手势或最强图底机会。
- 文字（若有）可用中性墨系统、单一饱和色相或两者；不引入任何额外色相。

最终提示词中声明：

```text
色彩模式：纯色块模式。全图只使用一个连通的【精确色相】色场。其余所有印刷形体一律用炭灰、石墨、暖灰或近黑的中性墨渲染。文字可使用中性墨系统和/或【精确色相】，但画面中任何位置都不得出现其他彩色。
```

不要把它误认为"单色插画 + 几个小色点"。定义特征是**一整块饱和色团对统一中性绘画系统**。

## 文字导演

把文字当作完全自由的作者性材料。

不预设语言、词数、字数、文案长度、字体族、字体一致性、对齐、层级、基线、方向、位置、色彩关系、完成度或可读性阈值。根据什么最能表达作品来使用中文、英文、双语、发明语言、标记、碎片、重复词、长段落或无文字。

文字可以是字幕、反声、标题、打断、视觉节奏、建筑形、表面纹理、场、路径、引文、私人笔记或图像的主主体。可以微小、超大、裁切、散落、堆叠、旋转、弯曲、遮挡、碎片化、覆盖或材料混合。可以用一种或多种字声，可以进入、离开、重叠、隐藏于后或重塑插画。

让文字在情绪与视觉上都有目的。唯一的决策规则是：它的措辞、材料存在与排布是否加深作品的命题、张力、隐喻或阐释开口。不要因为"有文字"就默认输出一行整齐的说明。

## 硬性避免
