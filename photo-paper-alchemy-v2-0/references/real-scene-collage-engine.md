# 实景拼贴引擎（模式 A）

**签名五律：真景为锚 · 插画成场 · 色彩成结构 · 撕纸成界 · 纸面会呼吸**

保留照片中不可替代的现场关系，以真实摄影作为锚点，让源自原图的抽象形状、单一高纯度色彩与可见的手撕纤维边缘向纸面延伸。

## 决策优先级

冲突时按此顺序解决：

1. 保留场景身份与关键空间关系。
2. 保持摄影部分真实可信。
3. 把复杂有机/重复细节压成少量大的可读形体与方向性手势。
4. 让插画成为大面积设计场，而不是描摹副本或小角落回声。
5. 让摄影、插画与那一个加入的色彩建立在同一条源衍生构图上。
6. 让加入的色彩成为改变平衡、运动、图底或意义的**结构**。
7. 在放大后的插画内部与周围保留大量安静空间。
8. 在主要材料交接处保留可见的手撕纤维边缘。
9. 添加一条克制、源感知的微文本，且不破坏画面层级。

**先保关系，再保细节；先删细节，再加装饰。**

## 空间不变量

在生成前明确写给自己：哪些关系**必须**存活。

- 核心主体的相对位置与方向；
- 主导地平线、路径、海岸线、注视或轮廓；
- 一到两个源特有形状；
- 原图重与静区域之间的张力。

插画可以简化解剖、纹理、比例和次要透视；不得发明无关场景，也不得用通用母题替换原空间逻辑。

## 抽象地图

对插画覆盖的每个部分，决定：

- **保留**：最多 1–2 个定义性形体或关系。
- **合并**：把重复的树、栏杆、窗、浪、人群、建筑细节合成一条节奏或一个轮廓。
- **省略**：删掉次要物体、表面细节、杂物、冗余轮廓。
- **转译**：把选定形体转成扁平剪影、断线轮廓、几何剪纸、墨场或重复标记。
- **留白**：在形体内部与周围刻意留纸。

不得复制照片里的每个物体，不得做"全场景描摹 + 复古纹理"。

### 默认抽象程度：中等

- 保留核心主体、主导手势和一个关键空间关系；
- 移除约 60–80% 的小描述性细节；
- 合并重复或相邻形体为更大块面；
- 用扁平墨、断轮廓、稀疏排线、半色调或纸剪取代写实明暗；
- 允许插画偏离字面比例或裁切，只要场景仍可识别；
- 至少保留一个不可混淆的源特有特征。

人脸、物体、建筑或地点会因此无法识别时，才降低抽象程度；用户明确要求或语义最小集仍然清楚时，才提高抽象程度。

## 插画语法

只选**一种**主要语法，最多一种辅助语法；不要把每种印刷工艺塞进一张图。

| 语法 | 形态 | 适用 |
| --- | --- | --- |
| 剪影主导 | 一个宽暗/灰块承载主体 | 人物、树、屋顶、船、强轮廓 |
| 轮廓主导 | 少量断线保留方向与关系 | 建筑、路径、栏杆、海岸线、手势 |
| 场域主导 | 一个不规则墨场或半色调暗示氛围 | 水、雾、天空、阴影、地面 |
| 节奏主导 | 重复标记压缩重复元素 | 桩、窗、浪、树枝、台阶、人群 |
| 剪纸主导 | 一到两个简化有机/几何剪纸承载场景 | 源图有强形状层级时 |

## 微细节压缩

源图越细密，越要简化——复杂度是简化更多的理由，不是印更多的理由。密集树冠、松针、叶、藤、草、花、发丝状枝条、人群、碎石等微纹理在插画中必须比摄影中安静。

- 叶/针密集区域：保留一个主树冠或树丛、1–3 个方向性枝势、最多两个次级簇、一个稀疏纹理样本。
- 省略约 85–95% 的叶片、针叶、细枝、重叠小枝与重复有机标记。
- 树与树叶默认用剪影主导或剪纸主导；节奏主导只能作为稀疏辅助痕迹，不能铺满。
- 把叶子画成成组块面、破碎叶裂、剪影阴影或短促断续节奏，绝不逐片画。
- 保留源特有的倾斜、树冠开口、枝向或光隙，而不是植物学细节。
- 多棵重叠的树合并成一个主团 + 最多一个次级对位团。
- 缩略图下若插画读起来像蕾丝、花边、珊瑚、密雕版或植物图鉴，就合并形体、删标记，而不是仅仅淡化。

### 密度控制

- 区分**场域范围**与**印刷密度**：插画可以影响海报的 45–70%，但其中大部分保持空白。
- 插画场内约 55–75% 保持安静；简单场景可放宽到 65–85%。
- 叶/微细节主导时：插画场 65–85% 安静，活跃插画约占全图 10–25%。
- 场域大时，活跃墨迹/剪纸/半色调约占全图 15–35%。
- 一个足以影响整体轮廓的主导插画团 + 一到两个支撑标记 + 一个克制的纹理场。
- 除纸色与那一个加入的色彩外，中性墨值最多两种。
- 偏爱不完整边缘、断续轮廓、裁切形体与内部留白，而非完全封闭的精细物体。
- 让空白纸分隔视觉观念。允许的碎点或幽灵痕迹只限于照片–插画过渡处。

**先把插画做大，再谈加细节。** 复杂有机场景：放大块面、减少标记数量。结果在缩略图下清晰可读，正常尺寸下仍"有意未完成"。

## 构图系统

### 布局族（从源几何选择，不要默认居中照片 + 下方文字）

| 布局族 | 说明 |
| --- | --- |
| 转型接缝 | 摄影约 30–50%；让一个真实主体/地平线/路径/阴影/轮廓跨过边界延续成更大的插画场 |
| 底层套印 | 摄影约 35–60%；宽而低密度的插画与色彩套印延伸到照片后方并部分穿透，不损伤定义性细节 |
| 照片锚 + 广袤场 | 摄影约 25–45%，插画场约 45–70%；事实场景是强锚点，抽象承载更宽构图 |
| 方向性切分 | 从 55/45 到 65/35 起步，但切分必须对齐真实地平线/注视/路径/结构边缘/汇聚，让插画选择性跨界 |
| 不规则碎片 | 照片碎片合计约 25–50%；核心主体放最大碎片，碎片间用共享插画团或色彩结构连接 |
| 记忆双联（可选） | 仅当用户明确要求"干净编辑式/抽象记忆面板/摄影与抽象对开"时使用：上部真实摄影 + 下部均匀无纹理象牙面板承载抽象母题与标题；比例按源图自适应（横图约 38–52% / 52–48% 反，竖主体约 55–68% / 32–45%），不用机械 50/50；面板保持干净（无纹理、无渐变、无颗粒） |

按源图的主导手势与视觉重量图选布局；这些数字是起点，用实际视觉重量校正，绝不为数字牺牲场景身份或插画清晰度。

### 艺术理论基线

图底清晰、视觉平衡（平衡重量而非面积）、一个主焦点、源线引导的运动、主从层级（避免无意的 50/50）、网格只在对源几何有用时使用、在注视/路径/波浪/斜向前方留出方向性呼吸空间。

## 手撕纤维边界

把摄影到纸面的边界当作**真实的纸物**。默认且首要的过渡方式是**可见的手撕纤维边缘**；直接转化、碎点或幽灵痕迹只能支撑交接，不能取代撕纸。

- 不规则的撕口轮廓：浅缺口、不平的起伏、柔和扇贝、偶尔更长的纤维拉扯。
- 一条窄的羽化纤维流苏：暴露的纸纤维与暖纸色打断照片边缘。
- 边缘局部轻微变薄、磨损、乳剂破裂或干颜料脱落。
- 自然不对称：有些段落接近平直，有些柔和毛糙，一两处更明显的撕拉受力点。
- 平扫行为，没有人为的纸张掀起深度。

控制边界：

- 活跃纤维带保持窄，约短边的 1–4%。
- 撕口轮廓在主照片–纸交接处清晰可见，覆盖照片可视周长的约 35–70%；既不要完美均匀的边框，也不要几乎看不见。
- 让插画或色彩结构在选定撕口段跨越、冒出或穿过，但撕纸本身仍可读。
- 碎点溶解、半色调碎屑或 1–3 处幽灵痕迹只作为一两处构图压力点旁的次级残留。
- 点的大小与间距不规则；符号保持不完整、微弱、非语言、印刷来源。
- 用纸色、石墨、炭笔、褪色棕黑或现有单一色相；不引入第二个色相。
- 缩略图下，撕纸边界应清楚建立材料分离，而不是变成装饰边框或第二个焦点簇。

**避免**：干净数字剪贴路径、清晰矩形蒙版、统一白描边、贴纸边框、装饰性波浪边、重投影、卷角、厚层纸深度、每边均匀的撕纸效果。

### 干净拼接变体（可选）

手撕纤维边缘是**默认**。仅当用户明确要求"干净编辑式""抽象记忆面板""摄影与抽象对开"或"不要撕纸"时，改用**干净拼接**：

- 摄影区域与抽象面板之间用干净、直接、无阴影的平面衔接；无撕纸、无相框、无投影、无拼贴胶带或样机效果。
- 抽象面板背景必须完全均匀、连续、无断裂：中性象牙色（如 #F3F0E8 或同色系和谐色），排除渐变、颗粒、纸张纹理、水彩底纹、污渍、扫描痕迹与压缩伪影。
- 面板气氛只能来自留白、距离、停顿、非对称、尺度差、有限标记与克制配色；不靠材质噪点制造气氛。
- 抽象母题约占面板宽度 30–42%、高度不超过面板高度的 28–34%，保留约 65–80% 干净空白（细长地平线类可放宽到宽度 45–68% 但保持低矮）。
- 标题（若有）只放在面板内母题下方或侧边（左下对齐或底部居中），使用优雅克制的编辑衬线体，颜色取照片或母题中较深的克制主体色，不用纯黑，不用最鲜艳的强调色抢视觉中心。

手撕与干净拼接二选一，不要在成品中混用两种边界语言。

## 色彩结构引擎

一个**加入的印刷色**是构图的一部分，不是最后的装饰。摄影部分的自然色不算额外色相。

### 选色相

先识别照片的主导色相族、冷暖、明度、饱和度与有意义的次要色，再按关系选择：

- **安静和谐**：更饱和的同类色。
- **聚焦对位**：互补或近互补色。
- **温度桥**：冷场加暖色，或暖场加冷色。
- **源共鸣**：强化照片中有意义的次要色。

给出精确颜色：全饱和钴蓝、不透明群青、干净番茄红、鲜明梨绿、柠檬黄、饱和洋红粉。把颜色放在源色、纸色与中性墨旁边判断，不要孤立判断。除非用户明确要求，不要用"苍白/柔和/褪色/粉彩/低饱和"削弱它。

### 选择一种集成方式

- **源延续**：把照片里的屋脊线、道路、云、窗、衣、影、植物、车面板等源特有形体延伸到照片边缘之外。
- **选择性替换**：把一个真实摄影区域转成扁平高纯印刷形，保留周围场景。
- **底层套印**：把宽幅半透明/半色调/错版色场放在摄影与插画之后并部分穿透。
- **反形**：从源轮廓、间隙、阴影或安静区派生一个彩色正形或负形。
- **方向性节奏**：沿注视、路径、栏杆、山脊、海岸线或汇聚线重复/拉伸一个源衍生彩色形。

选一个集成方式和一个主功能：焦点强化、对位砝码、照片–插画桥、视线引导、图底澄清或语义强调。

色彩结构必须至少满足两条测试：

- 轮廓/位置/节奏派生自提供的场景；
- 接触、重叠、替换、穿过或透出摄影或插画；
- 跨越照片–纸边界或在边界处转化；
- 重新引导视线或重新平衡视觉重量；
- 揭示或强化真实主体、空间关系、氛围或情绪张力。

**禁止**：孤立的矩形、角落补丁、通用圆、任意亮点、孤立笔刷色块只为了让海报"看起来有设计感"。几何形状只有在明显派生自源几何时才允许。可选地在 1–2 个更小的源锚定回声里重复该色相，保持从属。

### 面积匹配材料

- 不透明替换/剪纸形：约全图 2–6%。
- 半透明/半色调/错版套印：约 6–15%。
- 大型结构色场：约 10–20%（用此范围时降低不透明度、中性墨密度与竞争细节）。
- 照片本身色彩鲜艳时取下限；源图素净且加入色承担必要结构角色时取上限。
- 让高纯度穿过颗粒、墨晕、破覆盖与轻微错版存活，但不变成霓虹或数码光泽。

### 结构移除测试

心里把加入的色彩拿掉。如果视线路径、视觉平衡、图底关系、照片–插画连续性、场景解读基本不变，就重新设计。**颜色必须干活。**

## 微文本系统

- 用户提供文字时**逐字**使用，不翻译、不扩展、不重写、不加副标题、不加署名。
- 否则从场景写一行：具体场景短语或极短、广泛共鸣的诗意想法。不要虚构引用或署名任何人。
- 三种语言模式：中文、英文、中英配对。**默认中文**；用户提供或要求英文/双语时才切换。
- 中文 ≤8 个汉字；英文 ≤5 个词；配对时两个限制独立成立且两行语义相连。
- 英文三种形态：**单个词 / 关键词序列 / 极短短语**。不要求完整句子。
- 默认不写日期、时间、地址、坐标、天气读数、档案戳或序列号；除非用户明确要求或源本身以记录性信息为核心。
- 未提供文字时，选**观察到的感受，而不是元数据**：命名场景安静的余韵。
  - 强单体或单一情绪 → 单个词，如"地平线""雨""静止""漂移""庇护"。
  - 两到四个可见/氛围词 + 统一分隔符 → 关键词序列，如"云 / 山脊 / 沉默""玻璃 · 光 · 夏"。
  - 运动或情绪方向更重要 → 极短短语，如"雨后""坠落的光""快到家了"。
- 分隔符只选一种：逗号、居中点 `·`、斜杠 `/`、或 `&`。不混搭。

### 字型与材料

- 文字小：中文约海报高度 1.5–3.5%，英文约 1.3–2.8%；明确从属于照片与插画。
- 轻度不完美手写、打字机式活版印刷、淡铅笔、旧印章或干墨——选一种贴合场景的；禁用抛光数码展示字体。
- 英文偏爱小型老式打字机衬线或等宽机械体、略不平的基线、不匀墨压、克制字距。句首大写、小写或安静标题式；避免粗黑全大写展示字。
- 双语配对时：中文用淡手写/铅笔/克制宋体，英文用更小的打字机/活版印刷；共享对齐与墨族，读作一件纸物。
- 墨值安静：炭灰、暖灰、褪色棕黑、哑石墨，或对现有色相的极克制回声。可读即可，不用亮色。
- **可读性底线**：字迹可以适度不规则，但确切的字/词必须可读且拼写正确；生成后若文字扭曲、多字少字或拼写错误，属于硬性违规，针对性重生成一次。

### 位置与层级

- 放在现有安静纸区：下方、旁边、错位、或放大插画内部的安静口袋——不在脸上、定义性主体上或密集印刷区。
- 对齐源边缘、撕纸照片边缘、主导轴或视觉基线；周围留足呼吸空间。
- 默认单行（中文或英文）；双语用两行紧密关联的短行，明确主–次字号层级。
- 文字是视线路径的**最终停留点**，不是入口或焦点中心；视觉重量低于色彩结构，远低于核心主体。
- 不要为了支撑文字加装饰线、图标、标签、序列号、时间戳或伪编辑元数据。
