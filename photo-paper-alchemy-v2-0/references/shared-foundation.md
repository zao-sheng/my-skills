# 共享基础 · 纸面语言与纪律

所有模式共用的视觉系统。先读这里，再读对应模式引擎。

## 纸面身份

作品是一张被平放的扫描纸页，承载一个小而重要的视觉事件。不是商业海报，不是样机，不是数字画布。

- **画布**：默认竖向 3:5 纸感海报；用户另有要求或源图为横向时才用其他比例。
- **表面**：暖调纸张，可见纤维、细颗粒、扫描噪点、轻微旧化、哑光吸墨。默认无边框、无样机。
- **注意力几何**：留白是主动的参与者。拼贴模式以插画场内部安静为主（约 55–75%）；蒸馏模式以全画面留白为主（约 68–85%）。一个主视觉簇承担视觉事件，簇之外是真正的留白，不是被遗忘的区域。
- **深度**：平面正交扫描、漫射光、低到中对比、无硬阴影、无摄影样机深度。
- **气质**：安静、诗意、疏离、档案感、日记感、记忆感、极简编辑感。
- **材料语言**：焦点元素与文字必须活在同一个印刷/扫描世界里——半色调、复印软化、孔版印刷颗粒、活版印刷晕墨、扫描线、纸张边缘或轻微错版。

## 量化系统

这些数字是起点，不是教条。按实际视觉重量校正，绝不为了凑数字牺牲场景身份或插画清晰度。

| 维度 | 拼贴模式（A） | 蒸馏模式（B） |
| --- | --- | --- |
| 画布方向 | 默认竖向 3:5 | 按源方向：竖源 3:5，横源 5:3，方形/缺失 3:5 |
| 安静纸面 | 约 55–75%（插画场内部） | 约 68–85%（全画面） |
| 活跃主簇 | 插画墨迹约 10–35%（密叶场景 10–25%，场域大时 15–35%） | 约 12–32% |
| 高纯度色面积 | 约 2–20%（替换 2–6% / 套印 6–15% / 结构场 10–20%） | 约 0.8–3%（或活跃簇 10–30%） |
| 摄影占比 | 约 25–50% | 0%（禁用） |
| 手撕纤维带 | 短边 1–4% | 可选，约 1–3% |

## 色彩纪律

- 一个主高纯度色：钴蓝、群青、番茄红、梨绿、柠檬黄、洋红粉、橙。全图最多一个主色，加一个不超过主色面积约 10% 的极微弱回声（拼贴模式）或可选小回声（蒸馏模式）。
- 主色由主体、剪纸、色块、局部照片或粗体碎片承载；不要自动把它缩小成一个小圆点。
- 不要让"苍白、柔和、褪色、粉彩、低饱和"这类措辞削弱主色，除非用户明确要求。
- 纸与中性墨保持克制；饱和度只留给那个主色。

## 材料与印刷缺陷

选择一种或少量组合，让画面"来自印刷机而不是来自屏幕"：

- 半色调降级；
- 孔版印刷颗粒与套色偏移；
- 活版印刷墨晕与压痕；
- 复印软化；
- 扫描噪点与纸纤维；
- 旧纸斑驳；
- 轻微错版。

印刷缺陷必须**保持低对比**，不得压过主体，也不得把高纯度色洗成霓虹或数码光泽。

## 文字纪律

- 文字是安静编辑痕迹，不是广告标题。默认：一小句、一个词、或一行关键词序列。
- 排版气质：老式打字机衬线、书籍细衬线、等宽机械体、克制的小字号无衬线。禁止抛光数码展示字体、粗黑大写字、商业标题层级。
- 文字必须融入纸面：不均匀墨压、断墨、轻微吸墨、软边磨损，与海报同一种平面扫描质感。
- 把文字放在安静纸上、源边缘旁或撕纸边界附近；让它成为观看路径的**终点**，不是入口或焦点中心。
- 拼贴模式的微文本与蒸馏模式的作者性文字适用各自引擎的规则，但都遵守"文字为作品服务，而非给作品加注"这条底线。

## 通用避免项

全出血场景、商业标题层级、产品广告、商标、行动号召按钮、光滑样机、洁净界面白、电影光、硬阴影、3D、霓虹、赛博朋克、可爱卡通/动漫、时尚编辑戏剧感、密集拼贴簿、多色混乱、素材库写实感、长而整齐的正文块、复制来源参考图的文字/构图、水印。

## 观察纪律

- 对任何实际提供的图片，先检查再下结论：尺寸、比例、主体、细节、可见文字。
- 区分"观察到"与"推断出"。百分比是估算值，除非有测量。
- 文件缺失或不可读时，说明限制，不要编造分析。
