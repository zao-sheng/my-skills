# 提示词编译器

只编译能变成可见像素的指令。一个具体的可见决策胜过几个模糊的美学标签。不要在设计理论解释、文件路径、元数据或分析笔记上浪费提示词空间。

## 通用编译规则

- **提示词一律用中文撰写**（生图工具对中文理解良好）；只有必须精确渲染的成品内文字才保留其目标语言原文（如英文微文本本身）。
- 用决定性语言：说清哪些细节必须**消失**，和哪些形体必须**保留**一样清楚。
- 命名实际的可见载体：照片裁切、纸剪、墨块、标本、印刷插画、纹理窗、文字。不要用"极简""平衡""艺术感"这类不可渲染的抽象简写代替具体名词。
- 不要用"某处""极简""好看""艺术感""平衡"而不给出可渲染约束。
- 主题非海洋时，不要引入系船物、航海徽章或通用象形图标。
- 选择与选定配方相关的负向约束；不要浪费提示词空间罗列无关目录。
- 用户提供精确海报文字时逐字使用；否则按模式规则撰写短文本。需要可读的精确文字保持短；更长的词只作纹理。
- 低对比/哑灰只用于纸、照片与次级墨；主色保持饱和。

**双输出时**：模式 A 与模式 B 各编译一条独立提示词，分别传入参考图、分别生成、分别检查。两条提示词共享场景档案的事实描述，但构图、色彩与文字决策各自独立，不要互相复制。

## 传入照片的机制

两种模式都必须把**实际照片文件**传入生图工具，不能只靠文字描述——文字描述会丢失保真不变量（模式 A）或语义来路（模式 B）：

- 优先使用图像引用机制（如生图工具的图像路径参数）传入每个目标照片的本地路径。
- 目标照片只在对话中存在、没有本地路径时，使用"包含最近图像"机制，选择能覆盖全部目标的最小数量，上限 5 张。
- 两种机制不要在同一次调用中混用。
- 若没有任何机制能覆盖全部目标照片，请用户重新上传缺失的照片，而不是降级为纯文字描述。
- 模式 A 传入照片作保真锚点；模式 B 同样传入照片，但只作语义参考，提示词中必须声明禁止照片像素进入成品。
- 若生图工具不可用或无法接收参考图：明确说明限制并询问用户如何处理，不要假装成功。

## 模式 A · 实景拼贴四段式

1. **画布与注意力几何**：比例、纸张、布局、照片/插画占比、焦点区、安静场、视线路径、预留文字区。
2. **场景保真**：核心主体、空间不变量、什么保持摄影。
3. **插画场 · 色彩结构 · 撕纸边界 · 微文本**：保留/合并/省略/转译/留白决策；插画语法、复杂度压缩目标、场域范围、活跃密度；色彩集成方式、源形状、精确色相、材料、不透明度、功能、面积；可见手撕轮廓、纤维带、受影响周长、从属残留；精确文字、语言模式、形态、分隔符、层级、字型、墨值、尺度、位置。
4. **复制氛围与约束**：纸/扫描纹理、情绪温度、文字可读性、硬性避免。

## 模式 B · 影像蒸馏五段式

1. **表达与可见结果**：艺术命题、核心张力、视觉隐喻、阐释开口，以及具身它们的可见形式决策。
2. **画布与注意力几何**：源响应方向、3:5 竖或 5:3 横、纸、安静空间占比、簇大小、位置、层级、视线路径。
3. **蒸馏主体与创意改写**：语义核心、保留锚点、转化、省略、发明的源一致形体、插画语法。
4. **过渡边界 · 色彩模式 · 文字**：所选边界处理及其语义角色；精确色相、情绪动作、形态、位置、面积；模式专属排除；任何作者性文字材料及其视觉角色、物理行为、空间运动与图像关系。
5. **复制与硬性避免**：印刷/扫描纹理、情绪温度、无照片规则、禁止美学。

模式 B 的提示词中**始终包含**：

```text
禁止复现、嵌入、裁切、拼贴、描摹或保留参考图中的任何摄影像素与写实区域。成品必须只包含原创插画、纸张与文字。
```

并把照片标注为**仅语义参考**。

## 模式 A 的照片契约段

传入原照片作为参考图时，在第二段声明照片角色与保真不变量。用可验证的词而非"保持主体相似"这类含糊指令：

```text
把传入的照片作为真实锚点，保真度【高/中】。保持【不变量】可辨认。摄影区域必须保持忠实：只允许等比缩放或轻微构图裁切；禁止重画、延展、替换、修图或滤镜化其内容。只允许改变【允许的变化】；只引入【新增元素】。【随后接插画场指令。】
```

## 负向词库

按配方选择相关项：

```text
全出血场景、商业标题、产品广告、商标、行动号召按钮、光滑样机、洁净界面白、电影光、硬阴影、景深、3D 渲染、霓虹、赛博朋克、可爱卡通、动漫、时尚编辑戏剧感、密集拼贴簿、物体过多、多色混乱、素材库写实感、长段整齐文字、复制参考图文案、复制参考图构图、水印
```

## 生成后检查

- **最小硬性违规扫描（两种模式都做）**：照片像素泄漏（蒸馏）、摄影部分被重画/滤镜化（拼贴）、画布比例错误、可见水印或无关文字。只对硬性违规重生成一次。
- 模式 A：再对照 quality-gate.md 与保真不变量完整检查；失败则**收紧不变量、减少允许变化**针对性重生成一次。
- 模式 B：最小扫描通过后直接交付，不做例行检查或自动重生成，除非用户要求。
