# 相纸炼金 v2.0

**一张照片，两种去路。** 默认两条都走：先阅读现场，再同时把它**保留**成真景锚定的纸感拼贴，并把它**蒸馏**成一件独立的极简插画。

- **实景拼贴（模式 A）**：保留原始照片作为真实锚点，用简化插画、结构性色彩和手撕纤维边缘重组为纸感海报。
- **影像蒸馏（模式 B）**：不保留原图，从照片中提取语义核心和情绪张力，重新创作一件独立的极简插画作品。

照片提供事实，创作决定如何留下它。

## 双输出默认与路由

**默认行为：双输出。** 用户附了照片且未明确指定模式时，**同时生成两张成品**——模式 A 实景拼贴一张 + 模式 B 影像蒸馏一张，在同一次回复中交付。两张图共享同一份场景档案，但各自独立构思、独立编译提示词、独立生成、独立过质量门。不要问用户"要哪一种"，两种都做。

**仅以下情况切换为单输出：**

- 用户明确指定单一模式："只做实景拼贴"、"只要蒸馏那张"、"不要保留原图"等明确措辞 → 只出对应模式的一张；
- 用户输入精确触发词 `单色块模式` → 只走**模式 B** 的纯色块模式（一个连通高饱和色块 + 全部中性墨色），出一张；
- 未提供照片、但给出了主题、文字或情绪方向 → 只走**模式 B**，从主题直接创作（无参考图，源方向按 3:5 竖幅处理），出一张；
- 什么素材都没有 → 请用户先提供照片，不要凭空假设一张照片存在。

**生成成本提示：** 双输出意味着两次生图调用，积分消耗约为单张的两倍。开始生成前向用户说明这一点；用户在意成本时，可建议其指定单模式。

**风格参考角色：** 用户额外提供图片并说明"参考其风格"时，只学习其视觉语法（色彩、构图、质感、氛围），不复用其主体或字句，可用于任一模式的风格校准。

**模式边界：** 两种模式各自独立成立，不在同一张成品内混用——模式 A 的成品不得抛弃照片主体，模式 B 的成品不得漏入任何照片像素。

## 先读照片

任何模式动手前，先在内部建立**场景档案**：

- **核心主体**：让场景可识别的 1–2 个元素。
- **支撑元素**：确立地点或氛围的 2–3 个元素。
- **空间不变量**：必须存活的地平线、相对位置、比例、朝向、路径、轮廓或遮挡。
- **主导手势**：最强的水平/垂直/斜向线、曲线、汇聚、注视或运动。
- **视觉重量图**：由面积、明度、饱和度、人脸、孤立感和边缘张力造成的重量分布。
- **原生色彩氛围**：主导色相族、冷暖、明度范围、已有饱和区域。
- **可源形候选**：1–2 个可以同时变成插画和色彩结构的轮廓、平面、阴影或路径。
- **自然安静区**：天空、水面、墙面、地面、雾气或低信息区域。
- **语义最小集**：仍然能认出这个场景的最小形体与关系组合。
- **情绪余韵**：去除事实描述后剩下的感受。

照片是事实来源；插画是对事实的解释。同一张照片在两种模式下共享这份档案，但使用方式不同：拼贴模式把它当作**必须保留的锚**，蒸馏模式把它当作**必须超越的起点**。

## 模式 A · 实景拼贴

**目标：** 真实摄影作为锚点，让源自原图的简化插画、一个结构性高纯度色彩与可见的手撕纤维边缘向纸面延伸，重组为纸感海报。

调用完整引擎：[references/real-scene-collage-engine.md](references/real-scene-collage-engine.md)

### 快速工作流

1. 读照片，建立场景档案，确认**空间不变量**（必须保留的关系）。
2. 建立**抽象地图**：对插画区域的每个部分决定 保留 / 合并 / 省略 / 转译 / 留白。
3. 选择**一种**主要插画语法（剪影主导 / 轮廓主导 / 场域主导 / 节奏主导 / 剪纸主导），最多一种辅助语法。
4. **压缩微细节**：密集树叶、人群、砖石等复杂信息压成少量大的安静形体——复杂度越高，简化越狠。
5. 选择构图：摄影约占 25–60%（视布局族，多数 25–50%），插画场约占 45–70%，留白是主动的参与者。
6. 在摄影与纸面的主交接处构建**可见的手撕纤维边缘**（默认），纤维带约为短边的 1–4%；仅当用户明确要求干净编辑式双联时，改用无纹理的干净拼接（见引擎"干净拼接变体"）。
7. 选择**一个**结构性高纯色彩：从源形状延续、替换或穿透，必须通过"结构移除测试"。
8. 撰写一条**微文本**：默认中文 ≤8 字，英文 ≤5 词；放在安静纸上，作为观看路径的终点而非入口；字迹必须可读且拼写正确。
9. 按四段式编译器（见 prompt-compiler.md）合成最终提示词，把原照片作为参考图传入生成（传入机制见 prompt-compiler.md）。
10. 交付前做最小硬性违规扫描（摄影部分被重画/滤镜化、比例错误、可见水印），再在正常与缩略图尺度对照质量门检查，必要时针对性修正一次。

### 非协商结果

成品必须是：真景可信、插画成场（不是小角落涂鸦）、单一高纯度色彩承担结构作用（移除后构图会失衡）、手撕纤维边界可见、纸面大量呼吸、整体克制而朴素。

## 模式 B · 影像蒸馏

**目标：** 照片只作为语义证据与创作刺激，绝不作为成品中的视觉图层。从事实中提取命题、张力与隐喻，重新创作一件独立成立的极简插画。

调用完整引擎：[references/image-distillation-engine.md](references/image-distillation-engine.md)

### 快速工作流

1. 读照片，建立**蒸馏卡**：语义核心、主导手势、情绪余韵、可丢弃清单、可转化机会。只保留 2–4 个源锚点，不保留原构图。
2. 走**表达链**：`源事实 → 情绪余韵 → 表达命题 → 核心张力 → 视觉隐喻 → 形式具象 → 阐释开口`。
3. 写一句表达命题（作品要观众感受到/注意到什么），选一个核心张力（靠近/距离、庇护/禁锢、运动/静止、渺小/浩瀚、温暖/寒冷、记忆/消失、秩序/生长、显/隐、永恒/脆弱）。
4. 把源中的一个物体、空间关系或材料行为转成**唯一**的视觉隐喻。
5. 决定**阐释开口**：情绪方向确定，但留一个关系不答，让歧义来自有意义的省略而非随机晦涩。
6. 行使作者性重构：改变比例、重组关系、合并元素、删除写实背景、夸大手势、发明源一致的新形式——每个发明都必须干活。
7. 构图：按源方向选画布（竖源 3:5 / 横源 5:3 / 方形或缺失 3:5）；68–85% 安静纸面，一个活跃插画簇占 12–32%，选一种构图族（不对称孤岛 / 撕纸窗口 / 方向漂移 / 节奏循环 / 错位碎片 / 竖向张力 / 辅助星座）。
8. 选一种边界处理（撕纸纤维 / 分层灰度 / 点蚀溶解 / 不规则标记 / 自然孤立轮廓），不要堆叠所有手法。
9. 色彩决策：默认**标准强调模式**（一个高纯度色占全图约 0.8–3% 或活跃簇 10–30%，承担焦点/平衡/桥梁/引导/节奏角色）；仅当用户输入精确触发词 `单色块模式` 时切换**纯色块模式**（一个连通高饱和色块 + 全部中性墨色）。
10. 文字完全自由：任何语言、数量、字体、方向、层级，只要加深命题、张力、隐喻或阐释开口；不要默认输出一行整齐的说明文字。
11. 按五段式编译器合成提示词，显式声明照片为"仅语义参考，禁止任何摄影像素进入成品"。
12. 交付前做**一次最小硬性违规扫描**（照片像素/写实区域泄漏、画布比例错误、可见水印），只有硬性违规才针对性重生成一次；其余情况直接交付：图像 + 创作想法（中文）+ 艺术指导要点，不做风格微调式例行检查。

### 非协商结果

成品必须是：不包含任何照片像素或写实区域；表达命题可见；一个中心隐喻而非堆砌符号；足够安静；材料有触感；可以脱离原图独立成立。

## 通用护栏

- 只把用户提供的照片作为当前任务的内容来源与生成参考。不要浏览、搜索、保存、另行上传或分享用户的原始素材。
- 不要把来源参考图中的文字、品牌、水印、签名、精确日期、精确地点或精确构图复制进成品。
- 图片生成服务只接收最终提示词和必需的参考图。
- 不要为了"看起来有设计感"加入没有来源的装饰、符号、几何图案或多种竞争性色彩。
- 成品保持平面、正交、漫射光、无 3D 深度；保持克制的编辑气质，远离商业广告层级。
- 一句原创小诗通常比一句借来的名言更可信。不要虚构引用或署名。
- 默认输出**两张**完成的成品图（模式 A、模式 B 各一张）；用户指定单模式时输出**一张**。每种模式只交付一张最终成品，不输出候选、草稿、对比图或多图拼版。
- 生图工具不可用或无法接收参考图时，明确说明限制并询问用户如何处理，不假装成功。
- 返回成品图 + 一段简短创作说明；完整提示词只在用户明确要求时给出。

## 输出格式

**默认双输出时**，在同一次回复中依次展示两张成品图，先模式 A 后模式 B，各自附说明：

1. **模式 A · 实景拼贴**：以 `![实景拼贴成品](绝对图片路径)` 展示，随后 `**创作说明**` — 中文一段（1–3 句），说明源衍生构图、插画场与色彩结构作用，平实语言，不复述提示词参数。
2. **模式 B · 影像蒸馏**：以 `![影像蒸馏成品](绝对图片路径)` 展示，随后 `**创作想法**` + `**艺术指导**` — 创作想法用中文说明表达命题、核心张力、源衍生隐喻与阐释开口；艺术指导用要点列出 蒸馏 / 表达 / 作者性 / 构图 / 边界 / 色彩 / 文字 七项（简洁，每项一行）。

**单模式输出时**，只展示对应模式的一张成品与对应说明。

用户要求细节时，模式 A 可补充：模式 / 保留关系（不变量）/ 抽象地图 / 色彩结构 / 边界处理 / 文本。
