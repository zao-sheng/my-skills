# 案例档案

**相纸炼金** 的两种模式案例说明。每个案例按"原始照片 → 观察/蒸馏记录 → 最终作品"组织。以下为概念记录示例，供理解创作思路；实际使用时请以自己上传的照片为素材产出成品。

## 模式 A · 实景拼贴

### 示例 01 · 石与天空相遇（概念记录）

- **核心主体**：近景教堂塔楼与远处城市层次。
- **保留**：塔楼的真实石质表面、尖顶轮廓和城市的空间纵深。
- **压缩**：密集建筑统一为蓝色线描与网点印刷场。
- **转译**：天空、城市与屋顶共享同一蓝色结构，米色撕纸带切开并重新连接空间。
- **观看路径**：先进入宽阔天空，再落向城市纹理，最后停在真实塔楼。

### 示例 02 · 冬日渡桥（概念记录）

- **核心主体**：桥上人群与水面倒影。
- **保留**：人物与桥的空间关系、横向行进的方向。
- **压缩**：雪林转译为安静的蓝灰纸上场景。
- **边界**：手撕纤维边缘分隔摄影与纸面插画场。

## 模式 B · 影像蒸馏

### 示例 01 · 时间挥手回应（概念记录）

- **语义核心**：一个真实的人向远处沉默的石像挥手。
- **情绪张力**：靠近与距离、回应与无声、此刻与时间。
- **舍弃**：树林、台阶、长椅和全部摄影像素退出最终画面。
- **视觉隐喻**：人的手势化为黄色轨迹，穿过空白，向缩小的远方形体延伸。
- **材料选择**：黑色干墨人物、灰色石像与大面积旧纸共同强调时间感。

### 示例 02 · 雪落得很轻（概念记录）

- **语义核心**：雪地中的坐姿与冬衣色彩。
- **舍弃**：全部摄影像素。
- **转译**：松散纸片人物、大面积纸白保留雪的轻盈。
- **色彩**：一枚暖红色小块建立遥远的视觉回应。

## 如何产出自己的案例

1. 上传一张照片；
2. 用 `$photo-paper-alchemy-v2-0` 调用——默认双输出（实景拼贴 + 影像蒸馏各一张）；也可明确指定单一模式（"只做实景拼贴" / "只做影像蒸馏"）或使用触发词 `单色块模式`；
3. 按本技能的 SKILL.md 与 references 中的引擎执行；
4. 把"观察/蒸馏记录 + 成品"整理成上述格式的档案。
